# Contributing to QuickFixData EOS v1.0 Candidate

This file covers repository contribution rules for the EOS v1.0 candidate branch.

Guiding rules
- EOS specification (Parts 1–12) and the Consolidation are frozen and MUST NOT be modified.
- Only operational repository artifacts (README, docs/* supporting artifacts) and evidence placeholders may be updated in this candidate branch.
- Any change that would alter specification content requires explicit Governance approval and must be performed per docs/GOVERNANCE.md.

PR workflow
- Open a pull request to the candidate branch (recommended name: `eos-v1.0-candidate`).
- Include clear rationale and evidence references for changes.
- Do NOT merge into `main` without Approval Evidence.

Code of conduct
- Follow the project's standards for respectful collaboration.
